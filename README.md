🚀 Аркадный шутер
Игра про уничтожение астероидов на Python и Pygame.
🎮 Описание
Управляй космическим кораблём и уничтожай летящие астероиды. С каждой волной их становится больше и они летят быстрее. Реализована с использованием объектно-ориентированного программирования.
🛠️ Технологии

Python 3
Pygame

🚀 Запуск
bashpip install pygame
python main.py
🕹️ Управление

Стрелки — движение корабля
Пробел — выстрел
R — перезапуск
